Programmeren is denkwerk. De programmeertaal biedt je het gereedschap om
werkende computerinstructies te schrijven. Strings, numbers, booleans, arrays, loops, if/else,
functions, objects en classes zijn tools die je gebruikt om die instructies te schrijven.

Werkt de code niet meer, laat dan de file in de editor staan, zet de cursor in de open file en
ga terug met ctrl-z. De kans dat je de code weer kunt terugzetten met ctrl-z is je beste kans
om de code weer werkend te krijgen.
